### Observation

Time horizons of **1h and 6h leave 99.6% and 98% of failure
windows empty**. Effectively no Azure PdM failure is preceded
by an event in the same hour. Useful horizons are 24h and the
count-based (last-5 / last-10) windows.

Even at 24h, failure and control windows separate cleanly by
raw event count alone (failure mean 1.58 vs control 0.077),
so the event-count baseline is expected to be strong. Any
later claim that itemset or sequence mining helps must beat
that baseline on the same split.
